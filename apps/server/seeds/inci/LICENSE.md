# INCI dictionary data notice

`dictionary.json` contains ingredient names and spelling aliases derived from
the versioned mascara benchmark. It does not contain product photos, customer
reviews, ratings, prices, or ingredient-function claims.

Source: [Open Beauty Facts](https://world.openbeautyfacts.org/), made available
under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

Attribution: Contains information from Open Beauty Facts, made available under
the Open Database License (ODbL) 1.0.

The generated artifact is versioned and checksum-bound. See
`benchmarks/mascara-inci/corpus-v1.json` for source URLs, retrieval timestamps,
quality flags, and review metadata.
